# Prática 04 — Meu Diário Acadêmico

App de cadastro rápido de disciplinas do semestre, feito em Expo (React Native).

## Comando usado para criar o projeto

    npx create-expo-app@latest MeuDiarioAcademico --template blank

## Como rodar

    npm install
    npx expo start --web
